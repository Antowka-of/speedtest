# speedtest

Скрипт замеряет скорость интернета: делает 10 последовательных запросов к указанному адресу (например, тяжёлой картинке), дожидается полной загрузки каждого и печатает:

- среднее время запроса;
- общий объём скачанных данных;
- скорость в МБ/с (и в Мбит/с).

## Требования

Python 3.8+. Сторонние библиотеки не нужны — только стандартная библиотека.

## Запуск

```bash
git clone https://github.com/Antowka-of/speedtest.git
cd speedtest
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Пример вывода:

```
Запрос  1: 10.00 МБ за 2.21 с
Запрос  2: 10.00 МБ за 1.92 с
...
Запрос 10: 10.00 МБ за 1.92 с

Среднее время запроса: 1.88 с
Скачано всего:         100.00 МБ
Скорость:              5.33 МБ/с (42.62 Мбит/с)
```

Если запрос завершился ошибкой (сервер недоступен, 403/429 и т.п.), скрипт печатает причину и завершается.

Скорость считается как общий объём / суммарное время всех запросов. 1 МБ = 1024 × 1024 байт.
