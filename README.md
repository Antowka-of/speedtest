# speedtest

Скрипт замеряет скорость интернета: 10 раз подряд скачивает файл по указанному адресу (например, тяжёлую картинку) и печатает среднее время запроса, объём скачанных данных и скорость в МБ/с.

## Требования

Python 3.8+, без сторонних библиотек.

## Запуск

```bash
git clone https://github.com/Antowka-of/speedtest.git
cd speedtest
python3 speedtest.py
```

Скрипт попросит ввести адрес файла, например:

```
URL файла: https://proof.ovh.net/files/10Mb.dat
```

## Пример вывода

```
Запрос  1: 10.00 МБ за 1.72 с
Запрос  2: 10.00 МБ за 1.72 с
...
Запрос 10: 10.00 МБ за 1.66 с

Среднее время запроса: 1.74 с
Скачано всего: 100.00 МБ
Скорость: 5.76 МБ/с
```

Скорость = общий объём / суммарное время всех запросов (1 МБ = 2^20 байт).
